# Facilitator Cheat Sheet, Structure Reference

The cheat sheet is Danoosh's second-screen reference during the live session. It is glanceable, not a script. He should be able to drop his eyes to it at any moment and find his place in two seconds. Build it as a Markdown file (and offer a .docx if he wants one to print).

Tune every section to the specific cohort using the assessment data and the previous session's transcript. Generic cheat sheets are useless; the value is that it's built for this room.

## Structure

```
# Session [N] Facilitator Cheat Sheet, [Client]

**Date:** [Day, Date, Time, with timezone]
**Platform:** [Teams/Zoom] | **Duration:** [75 min / 2 hr]
**Second-screen reference for Danoosh**

---

## YOUR COHORT AT A GLANCE
[Ladder distribution as a quick visual or list. The one-sentence headline read,
e.g. "The team splits into thirds: a third haven't started, a third are drafting,
a third are building tools. The range is the point."]

## SESSION FLOW (with timing)
[Each block: name, minutes, what happens, the key thing to land. Include a hard
time-check note if pacing was a risk last session. Pre-mark one block as cuttable
if you run long.]

### Block 1 — [name] ([min])
- [Talking points, framings, the one line that matters]

### Block 2 — [name] ([min])
- [...]

[...continue for the full session...]

## KEY FRAMINGS / TALKING POINTS
[The mental models for this session, phrased the way Danoosh would say them.
Plain English. The analogies that work.]

## PEOPLE TO WATCH
**Will need support:** [Names + why + the specific move that helps each]
**Peer teachers to enlist:** [Names + their proven use case to surface]
**Wild cards / manage carefully:** [Anyone whose questions could pull the room off-track]

## PHRASES TO USE
- [On-brand lines that land for this cohort]

## THINGS NOT TO SAY
- [Brand-voice guardrails: no "transformation," no "AI literacy," no "ROI" in the room,
  don't call out anyone's level, etc. Tune to anything that risks landing wrong with this team.]
```

## Principles

- **Glanceable over complete.** If a line can't be read at a glance mid-session, tighten it.
- **Built from evidence.** Every "person to watch" and every "what landed" comes from the transcript or assessment data, not a guess.
- **Honor the brand voice** (see `references/voice-and-brand.md`), even though only Danoosh sees this. The phrases-to-use and things-not-to-say sections are where voice discipline shows up live. No em dashes anywhere: use commas, periods, or colons.
- **One concept, one main build.** If the flow has more than one core concept or more than one big build, flag it to Danoosh as a possible overload.
