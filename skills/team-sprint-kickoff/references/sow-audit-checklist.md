# SOW Audit Checklist

Use this checklist when reviewing any AI Team Sprint SOW. Extract every field and flag anything missing, ambiguous, or likely to cause scope creep.

---

## Required Fields

### Engagement Basics

- [ ] **Client name and title** (who signed)
- [ ] **Company name**
- [ ] **Engagement name** (AI Team Sprint, which tier?)
- [ ] **Date** of SOW
- [ ] **Consultant** (Danoosh Kapadia)

### Investment and Payment

- [ ] **Total investment** (dollar amount)
- [ ] **Payment schedule** (number of installments, amounts, triggers)
- [ ] **Stripe processing fees** (2.9% + $0.30 per charge, added to each installment)
- [ ] **Per-installment total** with fees calculated

### Program Structure

- [ ] **Total program duration** (weeks)
- [ ] **Pre-Sprint scope** (discovery interviews, guided setup, context file build)
- [ ] **Number of sessions** and **duration of each**
- [ ] **Post-Sprint scope** (wrap call, deliverables)
- [ ] **Cohort size range** (SOW number, e.g., 6-10)

### Session Curriculum

For each session, extract:
- [ ] Session number
- [ ] Title
- [ ] Duration
- [ ] One-sentence description of what it covers
- [ ] Expected outcome

### Deliverables (What Danoosh Owes)

- [ ] Context file
- [ ] Live sessions with recordings and recaps
- [ ] Applied challenges (one per session)
- [ ] Session materials (takeaway sheets, prompt templates, reference artifacts)
- [ ] Capability assessment (baseline, mid, final)
- [ ] Sponsor touchpoint calls (kickoff, mid-program, final readout)
- [ ] Post-Sprint program summary and recommendations

### What Client Provides

- [ ] Executive sponsor (named)
- [ ] Team lead (named or TBD)
- [ ] Participants (number, bringing real work)
- [ ] Protected weekly window (duration, consistency requirement)
- [ ] Discovery interview availability
- [ ] Orientation and onboarding materials
- [ ] Guided setup participation (team lead + tech sessions)
- [ ] AI note-taker recommendation (Fathom, Fireflies, etc.)

### Assessment Component

- [ ] **Included?** (Yes/No)
- [ ] **Tier** (which tier includes it?)
- [ ] **Frequency** (baseline, mid, post)
- [ ] **Deliverable format** (report to sponsor)
- [ ] **Administration** (who sends, who tracks completion)

### Assumptions

- [ ] **AI governance policy** (in scope or explicitly out of scope?)
- [ ] **HIPAA/data handling** (whose responsibility?)
- [ ] **Tool licenses** (who provisions, which platform?)
- [ ] **Training data controls** (turned off?)
- [ ] **PII handling** (participant responsibility clause?)
- [ ] **Technical issues beyond workspace config** (explicitly out of scope?)

### Target Dates

- [ ] Pre-Sprint start date
- [ ] Session 1 date
- [ ] Session cadence (weekly, specific day/time)
- [ ] Post-Sprint wrap date
- [ ] "Subject to mutual agreement" caveat

### Terms and Conditions

- [ ] **Session delivery** (virtual, platform specified?)
- [ ] **Rescheduling policy** (how many, notice period, missed = delivered?)
- [ ] **Cancellation terms** (mutual, prorated?)
- [ ] **Curriculum adaptation** clause
- [ ] **Confidentiality** clause
- [ ] **IP ownership** (frameworks = Danoosh, outputs = client, recordings = internal use)
- [ ] **Case study rights** (with written approval?)

---

## Scope Creep Red Flags

Flag any of these if they appear in conversation or context but are NOT in the SOW:

| Red Flag | Why It Matters |
|----------|---------------|
| Cohort size discussed verbally exceeds SOW range | More participants = more delivery load at same price |
| Governance policy drafting expected | SOW typically excludes this |
| 1:1 coaching for team lead or participants | Different product, different price |
| Agentic AI / advanced content requested | Beyond foundational fluency curriculum |
| SOP documentation as a deliverable | Consulting scope, not training scope |
| Enterprise IT troubleshooting | Explicitly out of scope in most SOWs |
| Additional discovery interviews beyond SOW count | Time creep |
| Custom tool integrations | Consulting scope |

When a red flag appears, name it to Danoosh with the generosity pattern warning. Let him decide, but make sure he decides consciously.
