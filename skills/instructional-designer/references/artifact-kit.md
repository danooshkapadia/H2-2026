# Artifact Kit

Templates for everything the design produces. Read at Phase 5, or when producing any single artifact. Produce the design brief FIRST and get sign-off before building the rest.

## 1. Session design brief (the source of truth)

Lead with the answer. Structure, in order:

```
# [Program], Session N Design: [Title]
Type / Status / Session date, length, platform / Cohort + tool

## Recommendation (lead with the answer)
One paragraph: the session in miniature, and why this design. The double duty:
surface goal + beneath-the-surface goal.

## The one behavior change this session installs
"Session N-1 moved them from A to B. This session moves them to C."
Then the identity line, quoted, said aloud at the open.

## Experience arc: the emotional shape of the [75] minutes
Numbered beats, each with a named feeling.

## The two engineered moments
The WOW moment and the TRANSFORMATION moment, each with the spoken line.

## Run of show
| Time | Block | Min | What happens | Energy |
Pre-marked cuts. The "start the centerpiece by X:XX" checkpoint. Never-cut list.

## [The hard mechanics section]
Whatever this session's riskiest mechanic is (dead-air plan, BYO-decision
scaffolding, the choice architecture), explained so it can be run by feel.

## [The menu / recipes] (if the session has builds or choices)

## Engineering the proof (the beneath-the-surface goal)

## Tie-backs to Session N-1

## Friction to remove (observed last time → fix)

## Assumptions and risks ([VERIFY] tags, fallbacks)

## Deliverables this design produces (after sign-off)

## Success metrics
| Metric | Baseline | Target | Source |

## Open questions (for Danoosh)

## References
```

## 2. Facilitator guide / second-screen cheat sheet

Glanceable, one purpose: keep Danoosh present, not reading. Contains: value anchor and frame for the session; the two tracks named with WHO is on stretch; run of show table with clock times; scripts only for the moments that must land word-for-word (the identity line, the vulnerable story, the wow line); per-beat cues, not paragraphs; contingency list; pre-session checklist with [VERIFY] items; people to watch (quiet, absent, struggling, and who gets a named callback).

## 3. Learner field guide (paint-by-numbers)

The proven skeleton (Base Camp pattern):

- Cover: kicker (LEARNER FIELD GUIDE · KEEP THIS OPEN), big title with a period, one-line promise, **Today's Win** box ("A rough start today is a success").
- **The ideas** page: 3-4 ideas to keep, each 2-3 sentences, the mantra in bold.
- **The activity** page(s): goal → "what to work on" → fallback box ("Nothing written? Use Option B") → numbered steps, each with a **COPY AND PASTE INTO CLAUDE box (mono, shaded)** → "what good looks like" → "where people get stuck."
- **Your climb this week**: the homework, at-a-glance strip (move, minutes, page, due date), then paint-by-numbers steps.
- **The moves you used**: 4 small habits in a grid. Signature block.

Rules: every prompt written in full (Role/Goal/Context/Guardrails/Steps/Output/Tone for anything complex); brackets [like this] mark the learner's turn; page references must be exact; time estimates on everything; the guide carries anyone who falls behind live pace.

## 4. Deck bullets (Gamma)

The deck illustrates; the field guide instructs. Sparse text, one headline font, one illustration language, one red accent per slide max, no garbled AI text. The structural metaphor drives the visual world. Commission the hero illustration separately (editorial mid-century, DK earth tones). Verify all stats before they hit a slide.

## 5. Follow-up system

Two-email rhythm around any gap or weekend: warm recap (closes the session, zero new asks beyond restating homework) + activation email (one job: come prepped; phone-actionable). Recap structure and length by format: exec 500-650 words bullets-forward; LEAD fuller. Team-lead cross-post with paste-ready text. Field guide travels with the recap. Named loop-closes in every recap. The recap/follow-up skills (team-sprint-session, post-coaching-follow-up) own final production; hand them the design.

## 6. Homework sizing card

Budget: 60-90 min total including anything already committed live. One car-friendly voice piece. Every prompt copy-ready. Due date + catch-up path for absentees. Nothing before holidays. Points at the persistent artifact. "Rough beats perfect" said out loud.

## 7. The ladder (assessment quick reference)

0 not started · 1 lookup · 2 drafting · 3 thinking partner · 4 workflow · 5 automation · 6 team redesign. Plain English to learners, never numbers. 1-2 rungs per program is honest. Built artifacts > self-reports. Capture live. Code conservative. Progress report, never a sales pitch.

## 8. Brand quick sheet

- **Fonts:** Helvetica Bold (titles, black), Helvetica Regular (khaki kickers, uppercase, letterspaced), Century (body; Georgia as stand-in). Mono for prompts (JetBrains Mono; DejaVu Sans Mono as stand-in).
- **Colors:** backgrounds #FFFFFF / #ECE3D7 / #EAEAEA; titles #000000; sub-headers #C5AA88; emphasis #CC0000 (once or twice per artifact, max); body #1A1A1A; muted #6B6B6B.
- **Layout:** asymmetrical Swiss grid, Scandinavian: clean, modern, generous white space. Minimum 12pt on screen deliverables.
- **Voice gut-check before anything ships:** Could this have been written for any cohort? (Make it unmistakably this team.) Any em dash a comma could replace? Any word that sounds like a vendor? Would the least technical person in the room read every sentence easily?
