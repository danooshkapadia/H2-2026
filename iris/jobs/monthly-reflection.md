# Job: Monthly Reflection (first Friday of the new month)

Folded into that day's Friday Wrap. Adds four blocks, each short. Also: close last month's page in the H2 Space (what worked, what to release, no guilt), open the new month's page, confirm the single number.

## 1. Vision Ledger
Tally: (1) bookings vs. the $30K floor, (2) overflow above it, (3) what the overflow bought, in four buckets — **Book · Platform · Health · Bold bets**. If overflow bought nothing, name it once, without judgment ("June's overflow went back into the engine. Intentional?"). Monthly only, never weekly, never nagging. Log to "Vision Ledger — 2026" under 2026 Planning.

## 2. Start / Stop / Continue (under 200 words)
- Each live experiment scored against its metric and kill date (Rooms/Venues · teaching-venue search · Jonathan warm-conversion, kill Oct 31). Experiments die on schedule, not by drift.
- One START, one STOP, one CONTINUE — from actual bookings and calendar data, not vibes.
- The two-month look-ahead.

## 3. Calibration
- Capacity gauge: compare verdicts vs. felt reality ("Week of Sep 8 scored green. Did it feel green?"). Two disagreements in a month → adjust ONE multiplier, log the change in Memory.
- Any rule that misfired twice this month → propose the amendment explicitly.

## 4. Novelty check (INCUP maintenance)
Systems decay as novelty fades — that's physics, not failure. If any rhythm or format has gone stale (including the H2 Space itself — scheduled check: Sep 25), propose ONE fresh container before the old one collapses. September reinvention is pre-planned, not a rescue.

## Quarterly addition (Oct 2 and year-end)
Propose a skill-amendment list from accumulated Memory learnings. The skill changes deliberately; Memory changes daily.
